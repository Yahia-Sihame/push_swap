# Push_swap

## Description

**Push_swap** is a 42 School project focused on sorting a stack of integers using a limited set of operations and the smallest possible number of instructions.

The program receives a list of integers and sorts them in ascending order using two stacks:

- **Stack A:** Contains the initial numbers and must be sorted.
- **Stack B:** Auxiliary stack used during sorting.

The project implements four sorting strategies, an adaptive algorithm that selects a strategy according to the initial disorder, and a benchmark mode to analyze sorting performance.

A bonus checker is also provided to validate the instructions generated by `push_swap`.

## Instructions

### Compilation

Compile the mandatory part:

```bash
make
```

Compile the bonus checker:

```bash
make bonus
```

Other Makefile commands:

```bash
make clean
make fclean
make re
```

### Usage

Run the program with a list of integers:

```bash
./push_swap 4 67 3 87 23
```

The adaptive algorithm is used by default.

### Available algorithms

Select a specific algorithm using one of these options:

```bash
./push_swap --simple 4 67 3 87 23
./push_swap --medium 4 67 3 87 23
./push_swap --complex 4 67 3 87 23
./push_swap --adaptive 4 67 3 87 23
```

### Benchmark mode

Use `--bench` to display information about the sorting process:

```bash
./push_swap --bench 4 67 3 87 23
```

Benchmark information is written to standard error, while sorting instructions are written to standard output.

The benchmark reports:

- Initial disorder percentage.
- Selected algorithm and its complexity target.
- Total number of operations.
- Number of times each operation was executed.

### Checker

The bonus checker reads instructions from standard input and verifies whether they correctly sort the stack.

Example:

```bash
./push_swap 4 67 3 87 23 | ./checker 4 67 3 87 23
```

Possible results:

- `OK` — Stack A is sorted and Stack B is empty.
- `KO` — The instructions do not produce the correct result.
- `Error` — Invalid arguments or instructions.

## Algorithms

The project implements four sorting strategies.

### 1. Simple — O(n²)

The simple algorithm uses a minimum-extraction approach.

1. Find the position of the smallest number in Stack A.
2. Determine the shortest direction to bring it to the top.
3. Use `ra` or `rra` to rotate Stack A.
4. Push the smallest number to Stack B using `pb`.
5. Repeat until Stack A is empty.
6. Move all elements back from Stack B to Stack A using `pa`.

This approach repeatedly searches for the minimum element and moves it to the auxiliary stack.

### 2. Medium — O(n√n)

The medium algorithm uses a chunk-based sorting strategy.

The numbers are divided into smaller groups, or chunks, according to their positions in the sorted order.

The algorithm pushes elements from Stack A to Stack B by processing these chunks, then moves the elements back to Stack A in the correct order.

This reduces the amount of searching and movement compared with the simple approach.

### 3. Complex — O(n log n)

The complex algorithm uses the Turk algorithm.

It calculates the cost of moving elements between the two stacks and chooses movements that help insert elements into their correct positions.

The implementation uses cost calculations, rotations, and reverse rotations to reduce the number of operations.

### 4. Adaptive

The adaptive algorithm analyzes the initial disorder of Stack A and selects a sorting strategy based on the result.

The disorder is calculated using the number of inversions:

\[
Disorder = \frac{Inversions}{n(n-1)/2}
\]

An inversion is a pair of elements where an earlier element is greater than a later element.

The strategy is selected according to these thresholds:

| Disorder | Selected algorithm |
|---|---|
| Below 0.2 | Simple |
| From 0.2 to below 0.5 | Medium |
| 0.5 or above | Complex |

This allows the program to adapt its sorting strategy to the initial arrangement of the numbers.

## Operations

The program uses the following 11 operations:

| Operation | Description |
|---|---|
| `sa` | Swap the first two elements of Stack A. |
| `sb` | Swap the first two elements of Stack B. |
| `ss` | Execute `sa` and `sb` simultaneously. |
| `pa` | Push the top element of B onto A. |
| `pb` | Push the top element of A onto B. |
| `ra` | Rotate Stack A upward. |
| `rb` | Rotate Stack B upward. |
| `rr` | Execute `ra` and `rb` simultaneously. |
| `rra` | Reverse rotate Stack A. |
| `rrb` | Reverse rotate Stack B. |
| `rrr` | Execute `rra` and `rrb` simultaneously. |

## Technical Choices

### Data Structure

The project uses a **doubly linked list** to represent the stacks.

Each node contains:

- An integer value.
- A pointer to the next node.
- A pointer to the previous node.

This structure allows efficient insertion, deletion, and movement of elements at both ends of the stacks.

### Parsing and Validation

The program validates its input before starting the sorting process.

It handles:

- Invalid characters and non-numeric arguments.
- Integer overflow and underflow.
- Duplicate numbers.
- Multiple numbers passed as a single string.
- Empty or invalid input.
